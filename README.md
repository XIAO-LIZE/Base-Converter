# 进制转换器 Base-Converter

🔢 实时进制转换工具 · 中英双语界面 · 纯Python标准库

---

### ✨ 功能 Features

- **实时转换** — 输入即转换，无需点击按钮
- **四进制同屏** — 二进制 / 八进制 / 十进制 / 十六进制 同时显示
- **中英双语** — 右上角一键切换中文 / English
- **一键复制** — 每个结果旁有 📋 按钮，点击即复制
- **二进制分组** — 每4位空格分隔，方便阅读
- **零依赖** — 纯 tkinter + 标准库，无需 pip install

---

### 🚀 使用 Usage

```bash
python main.py
```

或双击 `启动 Start.bat`

---

### 🎨 截图 Preview

选择输入进制 → 输入数字 → 四列结果实时刷新

| 二进制 | 八进制 | 十进制 | 十六进制 |
|--------|--------|--------|----------|
| 输入 BIN | 输入 OCT | 输入 DEC | 输入 HEX |
