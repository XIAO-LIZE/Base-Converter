# 进制转换器 / Base-Converter

[English](README.md) | 简体中文

一个用 tkinter 写的小工具，分进制转换和 ASCII 码表两个标签页。界面中英双语，只用 Python 标准库。

## 进制转换

在输入框里打字就实时转换，二进制、八进制、十进制、十六进制的结果显示在一屏里。

复制可以点结果行右侧的按钮，也可以直接点那串数字。复制成功后按钮会变成 ✓，标题旁边显示"已复制 二进制"。

输入这边做了些容错，免得打错了不知道该改哪。

- 二进制每 4 位加一个空格，长数字好读
- 负数按"符号 + 绝对值"显示，-5 就是 -101 / -5 / -5，不做补码
- 遇到非法字符直接告诉你是哪一个，比如「G」不是有效的十六进制字符；输入框空着时会提示当前进制允许哪些字符
- 接受 0x41、0b1010、0o17 这类前缀，也接受 1_000 和 1111 1111 这种分隔写法，从本程序复制出去的二进制可以直接粘回来
- 最多 10000 个字符，超了会提示；结果太长只截断显示，复制到的仍是完整值

## ASCII 码表

0 到 127 全覆盖，表头固定，往下滚动时不会跟着走。

- 打一个字符，右边列出它的码值；打多个字符会逐个列出
- 输入十进制码值，显示对应字符，控制字符用 NUL、LF 这样的写法
- 字符、码值和中文说明都能搜，右侧显示命中数量
- 带前缀的搜索限定到对应那一列，0x41 只匹配十六进制列，0b1010 只匹配二进制列
- 搜索框按 Esc 清空回到全部，转换页的输入框按 Esc 清空

## 运行

    python main.py

也可以双击 `启动 Start.bat`。它会依次试 `pyw -3`、`pythonw`、`py -3`、`python`，都找不到时会提示来看这份说明。

需要 Python 3.6+，tkinter 随 Python 一起装，不用 pip 装任何东西。整个程序就是 main.py 一个文件，拷到别的机器上也能跑。

## 其他

界面语言启动时按系统定：中文系统显示中文，其他系统显示英文；右上角的按钮可以随时切换，码表的"说明"列会跟着变。窗口和字号按屏幕缩放比例调整，高分屏不发虚，屏幕放不下时自动收缩。码表在搜索和切语言时只更新变化的内容，不会重建整张表。

想加一种语言，在 `TR` 里补一份对应语言的字典，再到 `ADJ` 里补上各进制的说法即可。
